AI governance lab

Eleven rounds, every output

The same run loop five times: write the guess, commit it, run the cases, read the verdicts, commit the results. Press Play to watch it, and read what the machine printed along the way. Each round says which machine ran it.

This is the working record behind the write-up. Rounds one to four ran on one MacBook Air with Python 3.9.6 (the result files say Darwin). The later work, from the 24 Oct audit onwards (the 14 extra cases and rounds six to eleven), first ran in a Linux sandbox with Python 3.11, and I then ran all of it again on the same MacBook Air with the same verdicts (the result files say which machine). The two held-out lists and the Track P walkthrough do not record the machine in their files. All of it uses made-up data about an invented lender. The expected result for every case was committed to git before the run.

Rounds five to eleven: the real output, on a Mac and in a sandbox

The 24 Oct audit round and rounds six to eleven were first run in a Linux sandbox (Python 3.11). On 25 Oct I ran all of them again on my MacBook Air (Darwin, Python 3.9.6). The verdicts are the same on both machines. Below, each round shows the Mac files first and the sandbox files after them, unedited. In each pair, one file is every case against my written guess, and the other is the control-off run: one control switched off at a time, in a copy of the code, to see whether the matching case noticed. Every name and ID number is made-up test data about an invented lender.
