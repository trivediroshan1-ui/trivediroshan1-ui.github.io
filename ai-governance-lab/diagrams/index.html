Architecture diagrams

Nine animated diagrams of how the lab works, in the order I would explain it: the lab as a whole, the request flow, where the filters plug in, how an agent gets access, the tamper-evident log, then the later rounds: the agent that only proposes, from HR to the directory, how a bypass is noticed and answered, and who owns what. Each one is an SVG file you can reuse.

These are drawn from the lab’s own code, not from a vendor diagram. Everything in them is made up: a lender called Kaveri Finance and test data that follows real formats on purpose. For the cases behind each diagram, see every use case, one by one.
