Architecture diagrams

Five animated diagrams of how the lab works: the request flow, where the filters plug in, how an agent gets access, the tamper-evident log, and the lab as a whole. Each one is an SVG file you can reuse.

These are drawn from the lab’s own code, not from a vendor diagram. Everything in them is made up: a lender called Kaveri Finance and test data that follows real formats on purpose. For the cases behind each diagram, see every use case, one by one.
