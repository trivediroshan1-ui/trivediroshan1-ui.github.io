Lab

Run the lab in your browser

The same Python scripts that produced every result in this lab, running on this page. Change an assumption, run again, and see which cases change. Nothing is installed and nothing leaves your browser.

  • Real scripts, unchanged
  • Python runs on your device
  • Made-up data only

How it works

The page loads Python (Pyodide, about 13 MB the first time) from this website, then runs the script you pick from the evidence folder exactly as published. Runs 5 and 6 check the guess file’s SHA-256 before they start, so if you edit a guess they refuse to run. That refusal is the point of locking guesses before any code.

  1. Pick a run and press Run. You should see one line per case ending in OK, or MISMATCH where my guess was wrong.
  2. Under the output, the page compares your results file with the published one.
  3. Find PARAMS near the top of Run 5 or Run 6, change one value, and run again. Run 6’s attacker_same_network is a good one to try.
  4. Change one word in the guess file and run again. The script stops and says the hash does not match.
