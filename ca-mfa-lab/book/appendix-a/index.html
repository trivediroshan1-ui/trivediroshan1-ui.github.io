Reproduction

On 14 November 2026 I reran all five scripts on a second machine, a Mac with macOS on x86_64 and Python 3.9.6. Every results file came out byte for byte identical to the published one. The log had 119 lines ending in OK and 5 ending in MISMATCH, the five Run 2 cases where my guess was wrong. The sixth wrong guess, Z21, is in a pair test that the per-case line does not show.
