The lab for your people

Run the scripts

  1. Install Python 3. The scripts use only the standard library.
  2. Download a script and its guess file from roshantrivedi.co.in/ca-mfa-lab/evidence/.
  3. Check the guess file's hash with shasum -a 256. It should match the table in appendix A.
  4. Run it, for example python3 -I run6.py guesses-run6.md. Each case prints its output, my guess and OK or MISMATCH.
  5. Open the script, change one value in PARAMS, run it again, and see which cases change.

The six hand tests

These need something a model cannot stand in for. Use a throwaway test tenant, made-up users and a spare key. Never call a real help desk, and never put a tenant name, password, code or token in your notes.

Report an exception

If you test any case in a real product and it behaves differently from my model, use the exception form on the lab's GitHub. It asks for the case ID, the product and version, what you saw and how you checked. Accepted exceptions go next to my result with a date, and my result stays.

Run it as a team workshop

  1. Pick one link from chapter 3 that your team owns.
  2. Before anyone opens the results, each person writes a guess for three cases in that link.
  3. Compare the guesses, then open the case pages and play each case one column at a time.
  4. For every case where someone was surprised, write down the assumption that would make your own setup different.
  5. Turn the surprises into checks: a policy review, a test in a test tenant, or a question for your vendor.
