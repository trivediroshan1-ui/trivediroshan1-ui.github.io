Check it yourself

  1. Get the evidence folder.Download nhi-lab/evidence/ from the repository.A folder containing guesses/, verify.py, run.py and run2.py.
  2. Check the hashes.python3 verify.pyFour lines starting with MATCH, then "4 of 4 guess files match the recorded hash." Exit code 0. Tested in the build sandbox on 2 November 2026.
  3. Re-run both runs.python3 run.py and python3 run2.pyThe same tables as RESULTS.md and RESULTS-stretch.md. In the build sandbox on 2 November 2026 the two results*.json files were identical to the committed ones except for the run_at time stamp.
What a pass tells youThe guess files are the ones I committed and the code gives the same answers twice. It does not tell you the models are right.

Controls nothing noticed

If you switch a control off and no result changes, one of two things is true: another control was covering it, or the control did not matter for that case. The lab cannot tell which. That is the point of the check, and it is why I kept these on the page.

What this audit cannot tell you

  • It is not independent. I wrote the guesses and the models, and a match shows my reasoning is consistent, not that a product behaves this way.
  • The hash proves a file did not change after I committed it. It does not prove when I wrote it.
  • I did not record which of the four first-run Mac commits holds which guess file.
  • A second person writing guesses for a few cases before seeing mine would be a stronger check. It is on the roadmap.
