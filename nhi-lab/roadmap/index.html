Rules I follow for every item

  1. Guesses first. Write what I expect, hash it, commit it, then write the code.
  2. Wrong guesses stay on the page next to the right answer.
  3. Every case gets a limit: what the control cannot see.
  4. Market facts get a date, a source and a trust label. If I cannot check one, I say so.
  5. No product is tested, so none is endorsed or criticised.

Where you can help

If you work on identity or privileged access and you think a case is wrong, or you can think of a variant that breaks a control, tell me. I will add it and keep the original on the page. If you would like to write guesses for a case before you see mine, I would like that most of all.
