Machine identities, tested in public · Appendix D

Glossary

The words used in this book.

TermMeaning
Agent identityA credential or account that an AI agent uses, kept separate from any person's login.
AttestationA signed statement, usually by an owner, that something is true. In the lab it was text and was not checked.
Blast radiusHow much damage a credential can do if it is stolen or misused.
Break-glass accountAn emergency account used when normal sign-in is down. It should be rare, loud and rotated after use.
Chain testA series of links an attacker needs. The test records which link each control stops.
ConsumerAn application or job that uses a secret. Change the consumer before the secret.
ControlA rule or check meant to stop a failure.
Front doorThe place where new identities are created or approved, and where the wrong ones can be refused.
Ghost credentialA key or account that nobody owns and nobody remembers.
Guess fileThe written expectations for a group of cases. It is hashed and committed before any code is written.
Hash (SHA-256)A 64-character fingerprint of a file. Change one character in the file and the fingerprint changes.
Just-in-time (JIT) accessAccess granted for a short window when it is needed and removed when the window ends.
LimitWhat a control cannot see. Every case should have one.
MaskedSwitching a control off alone changed nothing, because another control covered it or it did not matter in that case.
NoticedSwitching that one control off changed a result.
Non-human identity (NHI)An account or credential used by software and not by a person: a service account, API key, token, certificate, workload or agent.
OAuth grantPermission a person or organisation gives an app to act on their data, usually through a token.
ReplayUsing a stolen token again from somewhere else.
Roll forwardIssue a new value, move users to it, and only then remove the old one.
Service accountAn account an application or job uses to sign in.
SponsorThe person accountable for a vendor or agent identity, who is contacted if there is an incident.
TierA rating of how much damage an identity can do. Tier 0 can control identity systems or all of production, Tier 1 reaches production data or systems, Tier 2 reaches little. These tiers are a proposal. Your organisation sets the thresholds.
Wrong guessA number or a ranking in my guess that did not equal the result. The book keeps both.
