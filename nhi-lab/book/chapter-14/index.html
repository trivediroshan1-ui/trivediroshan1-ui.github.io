Machine identities, tested in public · Chapter 14

What is missing

The gaps I know about. A book that hid them would be weaker.

GapDetail
No product was tested.Every result comes from a small model I wrote. I make no claim about what any product does today.
One author for guesses, models and results.An outside reader writing guesses first is the stronger test. It is on the roadmap.
Two of the OWASP risks are thinly covered.Round 18 added a case each for insecure authentication (NHI4) and environment isolation (NHI8). Each risk still rests on two cases. The agentic risks ASI05 to ASI07 have no cases.
Sign-offs that are only text.Attestations, break-glass reasons, extensions and ticket numbers were accepted as written. I have not tested what checking them would take.
Nothing cloud-specific.AWS, Azure and Google Cloud each have their own key and role habits. The models are generic.
Catalogue rows that need a real environment.Some rows cannot be shown in a small model. The completeness register on the website gives each one a final status and a reason. Nothing was run for them.
No Kubernetes workload identity.It has its own tooling and is out of scope for this run.
No cost or performance data.The models cannot say what a control costs to run or how it slows people down.
No Indian rules check.RBI, CERT-In and the data protection law were not mapped. I make no compliance claim.
Licensed analyst reports were not read.Gartner, Forrester and KuppingerCole are licensed. The market chapter uses public primary sources.
Mac commit times are not recorded.I have the commit hashes. I did not write down exactly when each one was made, and I cannot tell you which file commit f902ea8 holds.
Accessibility and speed checks of the website pages.Lighthouse and a screen-reader pass are not run yet. They concern the web pages, not this book.
A hash proves a file did not change, not when I wrote it.It shows the guess file is the same file that was committed. The commit time is the only date evidence.

Where you can help

If you work on identity or privileged access and you think a case is wrong, or you can think of a variant that breaks a control, tell me. I will add it and keep the original on the page. If you would like to write guesses for a case before you see mine, I would like that most of all.
