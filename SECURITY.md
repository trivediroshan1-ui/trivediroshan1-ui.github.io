# Security

This repository is the source of roshantrivedi.co.in. It holds web pages, scripts and PDFs. It holds no secrets and no real customer or employer data. Everything in the lab is made up.

**Found a real problem?**

- A vulnerability in the website: use the contact in [security.txt](https://roshantrivedi.co.in/.well-known/security.txt), or open a private report under the *Security* tab (Report a vulnerability). Please do not open a public issue.
- A real secret or real personal data anywhere in this repository: report it privately in the same way.
- A mistake in a page, a book or a lab number: that is not a security report. Please [open an issue](../../issues/new/choose).
