# agent-skills

A collection of agent skills (SKILL.md folders) collected from open-source projects.

| Folder | Source | License |
| --- | --- | --- |
| `skills/composio/composio` | composiohq/composio, `skills/composio` (user-facing skill) | MIT, see `licenses/composio-MIT` |
| `skills/composio/*` (other) | composiohq/composio, `.agents/skills` (contributor skills) | MIT |
| `skills/playwright/playwright-cli`, `playwright-trace`, `playwright-component-testing` | microsoft/playwright (user-facing skills) | Apache-2.0, see `licenses/playwright-Apache-2.0` and `licenses/playwright-NOTICE` |
| `skills/playwright/*` (other) | microsoft/playwright, `.claude/skills` (contributor skills) | Apache-2.0 |

The contributor skills are written for working inside the upstream repositories, so they will mostly be useful there.
Each skill folder is self-contained and can be zipped on its own to upload as a skill.
