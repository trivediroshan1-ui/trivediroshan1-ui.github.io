How the labs work

Each lab asks a plain question about a control. I write down what I expect before I build anything, hash that file and commit it in public. Then I run the cases on made-up data and publish every result, including the guesses I got wrong. The models test my reasoning about a rule. They do not show how any vendor product behaves.
