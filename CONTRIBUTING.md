# Contributing

Found a mistake on the site, in a book or in a lab number? That is the most useful thing you can send.

1. Open an issue with the page address and what you think is wrong.
2. If you want to fix it yourself, keep the pull request small and say what it changes.
3. Run `python3 scripts/check-links.py`, `python3 scripts/check-numbers.py` and `python3 scripts/check-secrets.py` before you open it. The same checks run on every pull request.
4. Use made-up data only. No real people, credentials, companies or employer information.

Want to propose a new test case for the lab? That goes to the [lab repository](https://github.com/trivediroshan1-ui/ai-governance-lab/issues/new/choose).
