AI Governance · Decision Architecture

AI made producing work free. It didn't make deciding on it free.

A real reaction to a real conversation, checked against four independent studies, and answered with a structural control instead of a slogan.

Role
Independent Research & Control Design
Challenge
AI collapsed the cost of producing a document, a report or an access request to near zero. It didn't collapse the cost of verifying, judging or deciding on that output — and that unpaid cost doesn't disappear. It moves to whoever opens the file next.
Outcome
Named the mechanism, backed it with four independent studies, and specified a decision-package gate for HumanGate that rejects any AI-to-human handoff that hasn't done its own thinking first.
APPROACH

Three moves, in order

Start from a real reaction, not an abstract trend. Confirm it against evidence. Then design something that enforces the fix rather than just naming it.

01

Ground it in evidence

Cross-checked a personal reaction against BetterUp/Stanford's workslop research, MIT Media Lab's AI-ROI study, an NBER executive survey, and Goldman Sachs' economy-wide analysis — four independent measurements of the same effect.

02

Isolate the mechanism

AI compresses the cost of producing output. It doesn't compress the cost of verifying or deciding on it at the same rate — so that cost transfers to whoever receives the output next, concentrating upward toward the people with the least slack to absorb it.

03

Specify the fix

Designed a decision-package gate for HumanGate: a structural requirement, not a cultural norm, enforced at the exact point an AI agent hands a request to a human.

THE MECHANISM

The same handoff, gated two different ways

Today, an AI agent's request reaches a human ungated and the human pays the processing tax. The proposed fix validates the request before a human ever sees it.

THE CASE · A REAL REACTION

This didn't start as a thesis

It started as a reaction to a real conversation about AI and workplace productivity — written before reaching for any framework.

AI is creating situations challenging rather than making it easier when it comes to take a decision… it's not landing properly.

— Roshan, reacting in the thread
THE FIX

A decision-package gate, not a cultural norm

A norm only works if it's enforced. This is the control, specified at the exact point an AI agent hands a request to a human.

01

Requirement

Before HumanGate surfaces a request to a human, the originating agent must supply the options it considered, its recommendation, a confidence level, and the one question that actually needs human judgment.

02

Validation

The gate checks the package for completeness, not correctness — whether the agent did its own thinking, not whether its recommendation is right.

03

Rejection path

A request missing any required field bounces back to the originating agent automatically, with the specific gap identified, before a human ever sees it.

04

Integration

Sits alongside HumanGate's existing controls — time-boxed approvals, the live countdown to expiry, and risk scoring — as a fourth gate: has this request earned a human's attention.

⚠ Status: specified, not yet built. The decision-package gate is designed for HumanGate but not yet implemented — shipping it is the next stage of this work.
